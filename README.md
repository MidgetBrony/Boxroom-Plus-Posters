# Boxroom-Plus Posters

Add fully custom posters to your picture frames in **BOXROOM**.

Boxroom-Plus Posters extends the game's existing frame system by allowing you to replace game artwork with your own images. Your posters are saved with your room and automatically restored when you load your save.

---

## Features

- 🖼️ Use any PNG, JPG, or JPEG as a poster
- 💾 Posters are saved with your room
- 🔄 Automatically reloads custom posters after loading a save
- ⚡ Texture caching for fast loading
- 🎨 Works with existing BOXROOM picture frames

---

## How to Use

1. Place a picture frame in your room.
2. Hold **Shift**.
3. Click the frame.
4. Select an image from your computer.
5. Enjoy your new custom poster!

Supported image formats:

- PNG
- JPG
- JPEG

---

## Storage Location

Selected images are copied into:

```
%USERPROFILE%\AppData\LocalLow\NestedLoop\BOXROOM\Boxroom-Plus\Posters
```

The game stores only the copied version, so your original image can safely remain wherever you like.

---

## Installation

### Requirements

- BOXROOM
- MelonLoader

### Install

1. Install MelonLoader.
2. Copy `Boxroom-Plus-Posters.dll` into:

```
BOXROOM\Mods\
```

3. Launch the game.
